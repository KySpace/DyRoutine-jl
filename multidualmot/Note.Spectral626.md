# Spectrum 626 workflow

[`spectral626.jl`](spectral626.jl) converts the scope captures to JLD2 caches and produces the CH1 cycle, aligned CH2, time-to-frequency calibration, and calibrated spectrum figures. The default data directory is the `spectrum 626` folder configured near the top of the script. Its `config.yaml` controls the aligned display indices, tagged calibrations, and result traces/peak annotations.

## Processing sequence

1. **Cache scope CSV files as JLD2.** The script scans for files named `SDS#####.csv`. It reads the scope metadata and the three numeric columns (time, CH1, CH2), checks the sample count against `Record Length`, and saves the numeric vectors and metadata to a same-basename `.jld2`. An existing JLD2 is treated as the cache and its CSV is skipped.
2. **Load and smooth the channels.** Analysis loads `ch1_v`, `ch2_v`, and metadata from JLD2. Each channel is smoothed with a centered, symmetric 11-sample Gaussian kernel (σ = 2.5 samples, spanning 10 sample intervals). Replicate padding handles the capture edges. The smoothing is applied in memory after loading; it does not replace the stored arrays in the JLD2 cache.
3. **Construct the time axis.** Scope metadata supplies horizontal units and horizontal scale. The script uses the 14 horizontal divisions to map samples across the full capture duration in seconds.
4. **Find CH1 rising ramps and align traces.** CH1 minima and maxima are found from half-second bins with a 2-second dead-time, with the sample extremum refined within each bin. An aligned trace needs one complete minimum-to-maximum rising ramp containing a CH1 zero crossing; the ramp whose crossing is closest to raw time zero is selected. Its interpolated rising zero crossing is the time origin. The separate period table still lists only complete minimum-to-minimum cycles and is skipped if there are none.
5. **Find CH2 peaks for the aligned comparison.** On the selected rising ramp, the CH2 baseline is the mean after excluding the top 1% of values. Local maxima must exceed this baseline by 5 mV before the 50 ms dead-time rule is applied; this order prevents small candidates from suppressing real peaks. The strongest candidate in each dead-time window is retained.
6. **Build each tagged calibration using YAML references.** Each `calibration` entry has a unique `tag`, a `model` (`p4` or `cubicspline`), and a `source` list. For every source, the script detects a CH2 local maximum within ±1 ms of each configured aligned time. With `model: p4`, a detected 0 MHz peak fixes that source's $t_0$; when none is supplied, $t_0$ is fitted. References within one tag are fitted together using the existing unrestricted model

   \[
   f(u)=\alpha_i u\left(1+p_2u+p_3u^3+p_4u^4\right),\qquad u=t-t_{0,i}.
   \]

   The shape parameters $p_2,p_3,p_4$ are shared across sources in that tag; the scale αᵢ is fitted independently for each source. With `model: cubicspline`, each source gets its own shape-preserving monotone cubic Hermite interpolant through its detected references, ordered by aligned time. Its endpoint slopes use one-sided, monotonicity-limited derivatives. Set `extrapolation: linear` (the default) for endpoint-tangent lines or `extrapolation: quadratic` for quadratic tails determined by the first and last three references. Quadratic tails stop at their first turning point so the time–frequency mapping remains one-to-one; they require at least three references per source. The displayed $t_0$ is the time where this curve crosses 0 MHz. Each tagged calibration has its own figure. Solid model segments span the reference points; dashed segments extrapolate toward ±800 MHz or the first turn. The results and figures remain available as `calibration_results` and `fig_calibrations` arrays in an interactive Julia session, with `calibrations_by_tag` for lookup.
7. **Reconstruct result spectra and annotate configured peaks.** Each `result` entry selects a calibration by its `calibration` tag. The script loads and smooths its JLD2 channels and aligns time to CH1. For `p4`, a calibration source reuses its fitted $t_0$ and α; another source fits them from its `ref: true` peaks while retaining the calibration's shape parameters. The p4 trace extrapolates up to the result's ±900 MHz plot limits or its first turning point. For `cubicspline`, a calibration source reuses its interpolant directly; another source builds a new interpolant from its `ref: true` peaks, using the selected extrapolation method. The spline trace stops at ±900 MHz or a quadratic-tail turning point. The initial frequency-axis major ticks are spaced by 200 MHz; zooming in selects denser ticks automatically. The result figure has a menu with three precomputed states: raw voltage overlay, normalized overlay, and normalized replaced. Colored switches above the overview are generated from the unique result tags in `config.yaml`; each independently shows or hides that tag's wide scan, fine-scan overlay or replacement, peak markers, and labels in the overview. A separate `Peak markers + labels` switch shows or hides every overview peak marker and annotation together, across all result modes; the tag switches still control which traces are shown. These switches leave the fine-scan inset axes and their layout below unchanged. In both overlay states, a peak's nonempty `replace: ["dataN.mat", "case"]` loads `group_data.case.frequency` and `.voltage` from `individual reprocess/dataN.mat`, smooths its voltage with the same 11-sample Gaussian kernel used for CH2, and overlays it in the result trace's color at 50% opacity. Blank `replace` values are ignored. Raw mode uses smoothed volts directly. Normalized mode subtracts each full trace's CH2 mean after excluding its top 1% and divides all full traces by their shared largest corrected peak. For each fine scan, it excludes frequencies within `absFreq0 ± Δf`, where `Δf` is one quarter of that scan's frequency span, subtracts the mean smoothed voltage outside that band, and divides all corrected fine scans by their shared largest peak. Each group reaches 1.0 a.u. independently. In normalized replaced mode, each selected peak uses a ±4 MHz window around its configured frequency. The coarse and fine normalized curves are linearly interpolated onto one equally spaced frequency grid with as many samples as the smaller in-window sample count. A Hann weight is 1 at the center and 0 at the window edges; the displayed replacement is that weight times the fine curve plus its complement times the coarse curve. The coarse samples inside the window are hidden and the blended curve is drawn there. Each replaced peak specifies its inset with positive `row` and `col` indices or inclusive `[first, last]` spans. The plot derives the grid size from those positions, rejects overlaps, and keeps a spanning axis the same plotted height as a one-row axis. Overview labels use smaller text close to their peak markers, with nearby low peaks staggered vertically. Each inset also places its configured peak tag at the upper left. A companion `_fine_scan_detail.png` contains the insets alone. Calibration and peak finding use the original smoothed voltages in all three modes. Non-reference peaks are display annotations only: `time: exact` selects the plotted trace sample nearest the configured frequency; other frequency-configured peaks use the strongest peak within ±5 MHz, and peaks with only a time search near that time. Labels include the configured tag and detected time, frequency, and amplitude in the selected mode.

8. **Keep calculated result data for replotting.** `calc_calibrated_spectrum_results(path_data, calibrations_by_tag)` loads and processes the configured result data without drawing. The script stores its return value as the global `result_spectrum_data`, with `traces_result`, `traces_fine_scan`, and `points_annotations` also available as global aliases in the Julia REPL. `plot_calibrated_spectrum_results(result_spectrum_data, path_png)` draws the existing three-state interactive result from these arrays. The separate `calc_resampled_replaced_spectrum(result_spectrum_data)` merges each normalized replacement trace with its blended segments, then linearly resamples at 0.5 MHz outside labeled peaks and 0.05 MHz within ±2 MHz of each local highest sample near a label. Every such highest source sample is included exactly. The global `result_spectrum_selected_data` holds these curves. `plot_normalized_replaced_spectrum(result_spectrum_selected_data, path_png)` draws only those curves, without peak labels or insets, using the Times New Roman figure style and the requested 60 mm × 34 mm axis and rounded line caps and joins. The saved figure remains available as `fig_result_spectrum_selected`, and an interactive run displays it after export.
## Generated files

By default, outputs are written beside the data files:

- `SDS00014_CH1_vs_time.png` — high-resolution CH1 capture with detected extrema.
- `SDS00014_CH1_periods.csv` — complete CH1 periods and uphill/downhill durations and sample counts, when at least one complete period exists.
- `SDS<display indices>_CH2_aligned_periods.png` — one complete rising ramp per capture listed in a `display` entry, aligned to the rising CH1 zero crossing. CH2 traces have temporary 0.5 V vertical offsets; CH1 is scaled by 1/8 before using the same offset and a lighter color. These display-only adjustments are not used in calibration or result reconstruction.
- `spectrum626_time_frequency_calibration_<tag>.png` — one calibration and reference-residual figure per calibration tag.
- `spectrum626_calibrated_results.png` — the selected initial result state, with default frequency limits −900 to +900 MHz and 200 MHz major ticks.
- `spectrum626_calibrated_results_<mode>.png` — separate snapshots for `raw_voltage_overlay`, `normalized_overlay`, and `normalized_replaced`. Each also has a `_fine_scan_detail.png` companion when `replace` entries are present. The unsuffixed result and detail PNGs copy the selected initial state.
- `../Result/spectrum626_normalized_replaced.png` and `.pdf` — compact figure of the resampled normalized replacement traces, labeled by result tag, with no peak markers or insets. It has a −720 to +720 MHz x range, −0.05 to 1.05 a.u. y range, and no grid. If the existing PDF is locked, Julia writes `spectrum626_normalized_replaced_resampled.pdf` in the same folder.

## Running

```powershell
julia --project=. multidualmot/spectral626.jl
```

An optional first argument selects another data folder. `--skip-conversion` uses only existing JLD2 caches and avoids scanning/reading CSV files. `--display-only` produces `fig_spectrum` and its aligned-ramp PNG without requiring calibration or result entries in `config.yaml`; it also skips the SDS00014-specific CH1 plot and period CSV. `--calibration-only` skips the SDS00014-specific CH1 plot, period CSV, and aligned multi-file plot, but still produces the calibration and result figures. Either processing shortcut can be combined with `--skip-conversion`. The MHz result figure defaults to normalized overlay. Use `--result-voltage`, `--result-normalized`, or `--result-replaced` to choose the initial interactive menu state. Every run saves all three states separately. When calling `plot_calibrated_spectrum_results(result_spectrum_data, path_png)` directly, `normalize_amplitude=true` selects the normalized overlay unless `initial_mode` is specified.

In an interactive Julia session, evaluate `display(fig_result_spectrum_selected)` to reopen the final figure after export; its resampled arrays are in `result_spectrum_selected_data`.
