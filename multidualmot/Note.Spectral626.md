# Spectrum 626 workflow

[`spectral626.jl`](spectral626.jl) converts the scope captures to JLD2 caches and produces the CH1 and aligned CH2 signal figures, time-to-frequency calibration figures, the interactive spectrum, and the compact final result. The default data directory is the `spectrum 626` folder configured near the top of the script. Its `config.yaml` controls the aligned display indices, tagged calibrations, and spectrum traces/peak annotations.

## Processing sequence

1. **Cache scope CSV files as JLD2.** The script scans for files named `SDS#####.csv`. It reads the scope metadata and the three numeric columns (time, CH1, CH2), checks the sample count against `Record Length`, and saves the numeric vectors and metadata to a same-basename `.jld2`. An existing JLD2 is treated as the cache and its CSV is skipped.
2. **Load and smooth the channels.** Analysis loads `ch1_v`, `ch2_v`, and metadata from JLD2. Each channel is smoothed with a centered, symmetric 11-sample Gaussian kernel (σ = 2.5 samples, spanning 10 sample intervals). Replicate padding handles the capture edges. The smoothing is applied in memory after loading; it does not replace the stored arrays in the JLD2 cache.
3. **Construct the time axis.** Scope metadata supplies horizontal units and horizontal scale. The script uses the 14 horizontal divisions to map samples across the full capture duration in seconds.
4. **Find CH1 rising ramps and align traces.** CH1 minima and maxima are found from half-second bins with a 2-second dead-time, with the sample extremum refined within each bin. An aligned trace needs one complete minimum-to-maximum rising ramp containing a CH1 zero crossing; the ramp whose crossing is closest to raw time zero is selected. Its interpolated rising zero crossing is the time origin. The separate period table still lists only complete minimum-to-minimum cycles and is skipped if there are none.
5. **Find CH2 peaks for the aligned comparison.** On the selected rising ramp, the CH2 baseline is the mean after excluding the top 1% of values. Local maxima must exceed this baseline by 5 mV before the 50 ms dead-time rule is applied; this order prevents small candidates from suppressing real peaks. The strongest candidate in each dead-time window is retained.
6. **Fit the common calibration.** The current `common` calibration uses `model: spline_with_offset_and_error`, cubic B-spline knots from `knots`, and `regularisation` for the integrated squared second derivative. The script finds each configured calibration peak within ±1 ms of its aligned time, fits one B-spline to all detected references, and jointly fits one frequency offset per source. The first source's offset is fixed at zero. A natural cubic spline then interpolates each source's residuals, so its final frequency curve passes through all its reference points. The common spline and each residual spline continue linearly beyond their respective knot or reference-time spans.
7. **Plot and reuse the calibration.** `fig_calibration` and `fig_signal_calibrations` each contain one figure per configured calibration tag: offset-compensated reference points with the common model and each fitted source offset in the legend, source residual points with their natural interpolants (dashed linear tails outside each source's reference span), and continuous disagreement curves over the union reference-time span against the first source model's frequency. The two curves show the spread of full source models (`a_s + e_s`) and residual splines alone (`e_s`); residuals continue linearly outside each source's reference span. A `spectrum` source index must occur in the selected calibration. Its frequency axis uses the common spline, its fitted offset, and its residual spline; spectrum `peaks` only locate labels or replacement scans and do not refit the calibration. The `result` curves inherit those calibrated spectrum traces. `signal_calibration_data` and `calibrations_by_tag` retain the fitted objects in an interactive Julia session.
8. **Select and draw the compact result.** `calc_calibrated_spectrum(path_data, calibrations_by_tag)` loads and processes the configured `spectrum` data without drawing. The script stores its return value as the global `spectrum_data`, with `traces_spectrum`, `traces_fine_scan`, and `points_annotations` also available in the Julia REPL. `plot_calibrated_spectrum(spectrum_data, path_png)` draws the five-state interactive spectrum from these arrays. Each item in the separate `result` YAML block selects one spectrum trace by `tag`, optionally adds `shift` in normalized units (default 0), and lists the `peaks` to mark by frequency and annotation tag. Only selected traces appear in the compact figure, in result-block order. `calc_resampled_result(spectrum_data, entries_result)` merges each selected normalized replacement trace with its blended segments, then linearly resamples at 0.5 MHz outside its listed peaks and 0.05 MHz within ±2 MHz of each local highest sample near a listed frequency. Every such highest source sample is included exactly, and the configured shift is applied after resampling. The global `result_data` holds the shifted curves and peak metadata. `plot_normalized_replaced_result(result_data, path_png)` draws those curves with each listed peak marked by a dashed vertical line in the trace color at 40% opacity and a small rotated tag. The figure retains the Times New Roman style, 60 mm × 34 mm axis, and rounded data-line caps and joins. The saved compact figure remains available as `fig_result`, and an interactive run displays it after export.

9. **Draw the central CS-DSB fine scan.** The additional compact result selects the unique `CS-DSB` fine scan centered at 0 MHz from `spectrum_data.traces_fine_scan` and draws its normalized fine-scan samples alone, without a coarse scan or blended replacement. `plot_cs_dsb_fine_scan_result(result_cs_dsb_fine_scan_data, path_png)` uses the result style with no axis labels, 6 pt tick labels, and a 14 mm × 11 mm axis. Its x limits are −3.5 to 3.5 MHz with major ticks at −2, 0, and 2 and minor ticks at −3, −1, 1, and 3. Its y limits are −0.0002 to 0.001, with major ticks at 0, 4, and 8 × 10⁻⁴ and minor ticks at −2, 2, and 6 × 10⁻⁴; the rich-text superscript scale marker sits directly above the y-axis frame at the upper left. Its data and figure remain global as `result_cs_dsb_fine_scan_data` and `fig_result_cs_dsb_fine_scan`.
## Generated files

By default, outputs are written beside the data files:

- `SDS00014_CH1_signal.png` — high-resolution CH1 capture with detected extrema.
- `SDS00014_CH1_signal_periods.csv` — complete CH1 periods and uphill/downhill durations and sample counts, when at least one complete period exists.
- `SDS<display indices>_CH2_signal_aligned.png` — one complete rising ramp per capture listed in a `display` entry, aligned to the rising CH1 zero crossing. CH2 traces have temporary 0.5 V vertical offsets; CH1 is scaled by 1/8 before using the same offset and a lighter color. These display-only adjustments are not used in calibration or spectrum reconstruction.
- `signal626_time_frequency_calibration_<tag>.png` — one calibration and reference-residual figure per calibration tag.
- `spectrum626_calibrated_spectrum.png` — the selected initial spectrum state, with default frequency limits −900 to +900 MHz and 200 MHz major ticks.
- `spectrum626_calibrated_spectrum_<mode>.png` — separate snapshots for `raw_voltage_overlay`, `normalized_overlay`, `normalized_wide_scan_only`, `normalized_fine_scan_only`, and `normalized_replaced`. Each also has a `_fine_scan_detail.png` companion when `replace` entries are present. The unsuffixed spectrum and detail PNGs copy the selected initial state.
- `../Result/result626_normalized_replaced.png` and `.pdf` — compact figure of the result-selected, shifted normalized replacement traces, with configured peak guides and annotations but no zoomed insets. It has a −720 to +720 MHz x range, −0.05 to 1.05 a.u. y range, and no grid. If the existing PDF is locked, Julia writes `result626_normalized_replaced_resampled.pdf` in the same folder.

- `../Result/result626_cs_dsb_fine_scan.png` and `.pdf` — the normalized central CS-DSB fine scan in the small result style, with the configured close-up limits and ticks.

## Running

```powershell
julia --project=. multidualmot/spectral626.jl
```

An optional first argument selects another data folder. `--skip-conversion` uses only existing JLD2 caches and avoids scanning/reading CSV files. `--signal-only` produces `fig_signal` and its aligned-ramp PNG without requiring calibration or spectrum entries in `config.yaml`; it also skips the SDS00014-specific CH1 signal plot and period CSV. `--calibration-only` skips the CH1 signal plot, period CSV, and aligned multi-file signal plot, but still produces the calibration, spectrum, and final result figures. Either processing shortcut can be combined with `--skip-conversion`. The interactive spectrum defaults to normalized overlay. Use `--spectrum-voltage`, `--spectrum-normalized`, `--spectrum-wide-only`, `--spectrum-fine-only`, or `--spectrum-replaced` to choose its initial menu state. Every run saves all five spectrum states separately. When calling `plot_calibrated_spectrum(spectrum_data, path_png)` directly, `normalize_amplitude=true` selects the normalized overlay unless `initial_mode` is specified.

In an interactive Julia session, evaluate `display(fig_result)` to reopen the compact final result after export; its resampled arrays are in `result_data`. The large interactive figure is `fig_spectrum`. A full run also leaves `fig_signal_ch1` and `fig_signal`/`fig_signals` for the time-axis signal plots.
